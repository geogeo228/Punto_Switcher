# PuntoSwitcher (macOS, RU↔EN)

Свой авто-переключатель раскладки в духе Punto Switcher, написанный с нуля на Swift.
Ловит слово, набранное не в той раскладке (`ghbdtn` → `привет`), молча исправляет его и
переключает язык системы.

**Приоритет проекта — безопасность.** Инструмент по природе видит все нажатия, поэтому:

- **Ноль сети.** В коде нет сетевых вызовов и импортов. Ничего никуда не отправляется.
- **Ноль записи нажатий.** Текущее слово живёт только в RAM и затирается на границе слова.
  Никаких логов ввода / «дневника».
- **Ноль сторонних зависимостей.** Только системные Apple-фреймворки. Весь код читается глазами.
- **Уважение Secure Input.** В полях паролей macOS сам глушит перехват.

Единственная запись на диск — человекочитаемый файл исключений
`~/Library/Application Support/PuntoSwitcher/exceptions.txt` (только слова, которые ты сам
пометил «не трогать», см. ниже).

## Как работает детекция

Слово конвертируется в противоположную раскладку и проверяется системным `NSSpellChecker`:
«это реальное слово?». Правило: если сконвертированный вариант — настоящее слово, а исходный
нет — переключаем. Если оба валидны — не трогаем (защита от ложных срабатываний). Никаких
своих словарей не бандлим.

## Хоткей ⌃⌥U — перекинуть последнее слово

Одна клавиша (**Control+Option+U**, работает на обеих раскладках) делает всё, как в оригинальном
Punto:

- **Авто не сработало** (слово валидно в обеих раскладках или ты сам хочешь перекинуть) — жми
  хоткей, и последнее слово принудительно уходит в другую раскладку.
- **Авто сработало не так** — тот же хоткей перекидывает обратно (= откат).
- Работает и по слову, которое ты **ещё печатаешь** (до пробела), и по последнему завершённому.

## Обучение исключениям

Если авто-замену одного и того же слова ты откатываешь этим хоткеем **три раза подряд** — слово
уходит в исключения (`exceptions.txt`) и больше не трогается. Прерывание серии (авто-замена
другого слова между откатами) обнуляет счётчик.

## Сборка и запуск

```bash
swift build -c release
.build/release/PuntoSwitcher
```

При первом запуске macOS попросит выдать приложению доступ **Универсальный доступ
(Accessibility)** — System Settings → Privacy & Security → Accessibility. Без него перехват
клавиатуры не работает (в меню-баре появится предупреждение).

Значок **«Пу»** в строке меню: вкл/выкл авто-режима, статус, выход.

> Русский авто-режим требует установленного в системе **русского словаря проверки
> орфографии**. Если его нет — меню покажет предупреждение (System Settings → Keyboard →
> Text Input → добавить русский язык проверки).

## Тесты

```bash
swift test
```

Покрыта вся чистая логика: таблица раскладок, детектор, буфер слова, исключения, undo/обучение.

## Проверка инвариантов безопасности

```bash
# Зависимости: файла быть не должно
ls Package.resolved 2>/dev/null || echo "внешних пакетов нет"

# Сеть: символов быть не должно
nm -u .build/release/PuntoSwitcher | grep -iE 'URLSession|socket|connect|CFStream' || echo "сети нет"

# Во время работы — ноль исходящих соединений:
lsof -i -a -p "$(pgrep PuntoSwitcher)"

# Во время печати — нет записи текста ввода в файлы (кроме exceptions.txt по твоему действию):
sudo fs_usage -f filesys -p "$(pgrep PuntoSwitcher)"
```

## Структура

- `Sources/PuntoCore/` — чистая логика (тестируемая, без доступа к системе):
  `LayoutMapper`, `Detector`, `WordBuffer`, `ExceptionsStore`, `UndoManagerLite`.
- `Sources/PuntoSwitcher/` — системный слой: `EventTapController` (CGEventTap),
  `TextReplacer`, `InputSourceSwitcher` (TIS), `SystemSpellChecker` (NSSpellChecker),
  `HotkeyController` (Carbon), `MenuBarController`, `AppController`.

## Известные ограничения v1

- Только стандартные раскладки US QWERTY и русская ЙЦУКЕН.
- Undo (`⌃⌥U`) рассчитан на нажатие сразу после ошибочной замены.
- Автозапуск при логине пока настраивается вручную (System Settings → General → Login Items).
